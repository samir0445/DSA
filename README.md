## 🧠 Problem-Solving Approach

For each problem, I focus on:

1. Understanding the problem
2. Identifying the appropriate pattern or data structure
3. Developing a brute-force approach when useful
4. Finding an optimized solution
5. Analyzing time and space complexity
6. Implementing the solution in C++
7. Testing important edge cases

The goal is not only to solve problems, but also to understand **why a particular approach works and how it can be optimized**.
